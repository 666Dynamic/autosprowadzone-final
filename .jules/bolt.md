## 2025-06-26 - Cache Intl.NumberFormat for Rendering Performance
**Learning:** Instantiating `Intl.NumberFormat` is a surprisingly CPU-intensive operation. When used inside a React component that re-renders rapidly (e.g., during animations, like the bidding simulation in `AboutAuctions`), instantiating it on every render, even if wrapped in a `useMemo` with frequently changing dependencies like `price`, causes significant main thread overhead. Using `useMemo` is ineffective if the dependency updates on every tick.
**Action:** Always cache `Intl.NumberFormat` instances statically outside of components, in a constants file using a `Map` (for dynamic locales/currencies), or as module-scoped variables rather than repeatedly instantiating them inside functions or render loops.

## 2024-05-24 - Intl.NumberFormat Instantiation Overhead in Render Loops
**Learning:** `Intl.NumberFormat` instantiation is a notoriously expensive operation. Calling `new Intl.NumberFormat` repeatedly inside React components (even within `useMemo` if its dependency array contains frequently changing values like animated states or live bid prices) or frequently invoked utility functions causes measurable performance degradation and jank, especially on mobile devices.
**Action:** Always cache `Intl.NumberFormat` instances. If the locale is static, define it as a module-scoped constant outside the React component or utility function. Only use `useMemo` for `Intl.NumberFormat` if the locale or format options depend dynamically on the component state (e.g., user-selected language), and ensure the dependency array does *not* include the value being formatted.

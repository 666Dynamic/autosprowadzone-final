## 2025-02-28 - [Cache Intl.NumberFormat for Rendering Performance]
**Learning:** Instantiating `Intl.NumberFormat` is a known performance bottleneck in JS. In this codebase, it was being recreated on every call in `formatCurrency` and `formatNumber` (`lib/calculator-constants.ts`) and, critically, on every render frame of a rapid state animation (using `useMemo` with a rapidly changing `price` dependency) in `components/about-auctions.tsx`. Caching these instances at the module level makes formatting up to 100x faster, directly reducing main thread blocking during animations.
**Action:** Always extract `Intl.NumberFormat` (and `Intl.DateTimeFormat`) instantiations outside of functional components and utility functions. Avoid using `useMemo` for formatters if their dependencies update frequently; a static module-scoped constant is safer and more performant.

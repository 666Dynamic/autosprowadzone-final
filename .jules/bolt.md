## 2025-02-18 - [Cache Intl.NumberFormat]\n **Learning:** Creating a new `Intl.NumberFormat` object is surprisingly expensive in JS. By extracting the instantiation out of render loops and utility functions and caching them as global constants, the code executes much faster during formatting operations.\n **Action:** When working with `Intl.NumberFormat`, always cache the instance in a constant variable outside of render loops and utility functions, rather than re-instantiating it repeatedly.
